# 🧠 **Brain Tumor Classification using Deep Learning**

## 📌 **Project Overview**

* This project is a deep learning-based brain tumor classification system.
* It uses a **Convolutional Neural Network (CNN)** for MRI image classification.
* The system includes **training, evaluation, and GUI interface** modules.
* It classifies brain MRI scans into four categories.

---

## 🎯 **Objective**

* Detect and classify brain tumors from MRI images.
* Train a deep learning model for medical image classification.
* Evaluate model performance using standard metrics.
* Provide an easy-to-use GUI for real-time predictions.

---

## 🧬 **Dataset Classes**

* Glioma Tumor
* Meningioma Tumor
* Pituitary Tumor
* No Tumor

---

## 🤖 **Model Details**

* Model Type: **Convolutional Neural Network (CNN)**
* Framework: TensorFlow / Keras
* Input: MRI brain images
* Output: 4-class classification
* Includes:

  * Model training module
  * Model evaluation module
  * Saved trained model for inference

---

## 📊 **Training Module**

* Loads and preprocesses dataset
* Applies image resizing and normalization
* Trains CNN model on labeled MRI images
* Saves best-performing model

---

## 📈 **Evaluation Module**

* Evaluates trained model performance
* Measures accuracy and loss
* Uses validation dataset
* Displays evaluation metrics and results
